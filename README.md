# Cognifyz Technologies - Power BI Internship

## Overview
This repository contains the completed tasks and project deliverables for the **Power BI Intern** role at **Cognifyz IT Solutions Pvt. Ltd.** The project focuses on retail investor behavior, portfolio avenue preferences, risk appetites, and objective analysis across 40 survey respondents.

## Tasks Breakdown
- **Task 1: Data Exploration & Summary** – Core statistics, investor participation, and demographic distribution.
- **Task 2: Gender-based Analysis** – Comparative study of asset class preference and market exposure by gender.
- **Task 3: Objective Analysis** – Correlation between investor savings objectives and chosen financial instruments.
- **Task 4: Investment Duration & Frequency** – Holding period distribution and portfolio tracking habits.
- **Task 5: Reasons for Investment** – Underlying rationale across equity, mutual funds, government bonds, and fixed deposits.
- **Task 6: Source of Information** – Evaluation of financial advisors, digital platforms, and print media impact.
- **Task 7: Master Executive Dashboard** – Unified interactive Power BI report with cross-filtering, slicers, and summary KPIs.
